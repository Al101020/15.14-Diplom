2. С нуля, с состоянием
Если вам нужна особая логика (например, задержка появления, анимация или зависимость видимости 
от внешнего состояния), реализуйте это через React-хуки (useState).
Пример скелета:
import { useRef, useState } from 'react';

function MyInput({ onFocus, onBlur, message }) {
  const inputRef = useRef(null);
  const [showTooltip, setTooltipShow] = useState(false);

  useEffect(() => {
    if (onFocus) {
      setTooltipShow(true);
    }
    if (onBlur) {
      setTooltipShow(false);
    }
  }, [onFocus, onBlur]);

  return (
    <div>
      <input type="text" ref={inputRef} placeholder="Введите значение" />
      {showTooltip && <div className="tooltip">Это подсказка!</div>}
    </div>
  );
}
Здесь useRef позволяет получить доступ к DOM-элементу, а useEffect управляет состоянием showTooltip.
